# 汉字构字法·思维导图

## 中心主题：汉字不是死记硬背，而是有规律的组合系统

```
                        汉字构字法
                             │
        ┌────────────┬───────┴───────┬────────────┐
        │            │               │            │
      象形          指事            会意          形声
    画出来         标出来          合起来         拼起来
        │            │               │            │
    独体基础字    象形+符号      字+字=新字    形旁+声旁
        │            │               │            │
     ┌──┴──┐      ┌──┴──┐       ┌──┴──┐      ┌──┴──┐
     │     │      │     │       │     │      │     │
   自然  人体   位置  状态    同体会意 异体会意  表意  表音
     │     │      │     │       │     │      │     │
   日月  人口   本末  上下    从林森  明问囚   氵钅  工可
   山木  火门   旦    中      炎焱  闪呆    女    马且
```

## 一、象形：画出来

**定义**：直接描摹事物形状。

**核心**：像简笔画，一看就懂。

```
象形
├── 自然类
│   ├── 日 —— 太阳，圆形中加一点
│   ├── 月 —— 月牙，弯月形
│   ├── 山 —— 山峰，三峰并立
│   ├── 木 —— 树，上枝下根
│   └── 火 —— 火焰，火苗升腾
│
├── 人体类
│   ├── 口 —— 张开的嘴，方形
│   └── 人 —— 侧身站立的人
│
└── 人造物类
    └── 门 —— 双扇门，像两扇门板
```

**组合能力**：

```
木 → 林 → 森
口 → 问 → 囚
日 → 明 → 早
人 → 从 → 众
火 → 炎 → 焱
门 → 闩 → 闪
```

**一句话**：象形是汉字的“根”，是最基础的零件。

---

## 二、指事：标出来

**定义**：在象形字上加符号，指出意义所在。

**核心**：画不出来的意思，用符号标出来。

```
指事
├── 在“木”上加符号
│   ├── 本 —— 木下加一横 → 树根
│   └── 末 —— 木上加一横 → 树梢
│
├── 在“日”上加符号
│   └── 旦 —— 日下加一横 → 日出地平线
│
└── 用横线表示位置
    ├── 上 —— 长横上加短横 → 上方
    └── 下 —— 长横下加短横 → 下方
```

**一句话**：指事是“象形+提示符号”，数量少，但很关键。

---

## 三、会意：合起来

**定义**：把两个或几个字的意思合在一起，形成新字。

**核心**：1+1=新意义。

### 3.1 同体会意（同一个字叠加）

```
同体会意
├── 人 + 人 = 从 —— 跟从
├── 人 + 人 + 人 = 众 —— 众人
├── 木 + 木 = 林 —— 树林
├── 木 + 木 + 木 = 森 —— 森林
├── 火 + 火 = 炎 —— 热
├── 火 + 火 + 火 = 焱 —— 火焰多
├── 女 + 女 = 争吵
└── 女 + 女 + 女 = 奸
```

**规律**：

- 两个 → 程度加深
- 三个 → 数量极多

### 3.2 异体会意（不同字组合）

```
异体会意
├── 人 + 口 = 囚 —— 人被困住
├── 人 + 门 = 闪 —— 人从门中逃出
├── 木 + 口 = 呆 —— 树上有口，会说话的树很呆
├── 木 + 火 = 焚 —— 火烧树林
├── 日 + 月 = 明 —— 日月同照，明亮
├── 门 + 口 = 问 —— 门里发问：“有人在家吗？”
└── 门 + 木 = 闩 —— 门里放木板，门闩
```

**一句话**：会意是“意义的加法”，最有趣、最好记。

---

## 四、形声：拼起来

**定义**：形旁表意，声旁表音。

**核心**：一半管意思，一半管读音。

```
形声
├── 形旁：氵（水）
│   ├── 江 —— 工（声旁）
│   ├── 河 —— 可（声旁）
│   ├── 湖 —— 胡（声旁）
│   └── 海 —— 每（声旁）
│
├── 形旁：女
│   ├── 妈 —— 马（声旁）
│   ├── 姐 —— 且（声旁）
│   └── 妹 —— 未（声旁）
│
└── 形旁：钅（金）
    ├── 铜 —— 同（声旁）
    ├── 铁 —— 失（声旁）
    └── 银 —— 艮（声旁）
```

**数量**：占现代汉字 80% 以上。

**一句话**：形声是“批量造字法”，效率最高。

## 五、四类构字法对比表

| 构字法 | 核心口诀 | 构造方式 | 例子 | 特点 |
|---|---|---|---|---|
| 象形 | 画出来 | 描摹事物形状 | 日、月、山、木、人、口、火、门 | 最基础，独体字 |
| 指事 | 标出来 | 象形+提示符号 | 本、末、旦、上、下 | 数量少，指示性强 |
| 会意 | 合起来 | 字+字=新字 | 从、众、林、森、明、问、囚、闪、呆、焚、炎、焱 | 有趣，易记，意义相加 |
| 形声 | 拼起来 | 形旁+声旁 | 江、河、湖、海、妈、姐、妹、铜、铁、银 | 数量最多，效率最高 |

## 八、结语

汉字像一套积木：

- **象形**是零件
- **指事**是标记
- **会意**是组合
- **形声**是量产

掌握这四类构字法，就掌握了汉字学习的底层逻辑。

**一句话：**

> 象形画形，指事标位，会意合义，形声拼音。  
> 掌握规律，汉字不难。
